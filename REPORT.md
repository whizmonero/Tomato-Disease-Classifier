The Tomato Disease Classifier was developed using the PlantVillage dataset obtained from Kaggle. The dataset contains labeled images of healthy tomato leaves and tomato leaves affected by Early Blight, making it suitable for supervised image classification using deep learning. The application allows users to upload a tomato leaf image through a Streamlit web interface, after which the trained Convolutional Neural Network (CNN) predicts whether the leaf is healthy or infected and displays the prediction confidence. During development, challenges included configuring the Python virtual environment, GPU compatibility, model path management, and package dependency issues. Deployment on Streamlit Community Cloud was further complicated by TensorFlow's incompatibility with the default Python 3.14 environment. Future improvements include supporting more tomato diseases, enhancing the user interface, improving model accuracy with additional training data, and deploying on a platform with full TensorFlow compatibility.
